# FCMB Pensions demo

A clickable prototype of the redesigned FCMB Pensions app.

## Run it on this computer
- Double-click **Open demo.bat** (or index.html). It opens in your browser.
- Or double-click **Run local server.bat** to serve it at http://localhost:5173 (needs Node.js or Python).

## Demo tips
- Any login details work. Any verification code works.
- "Restart demo" (left panel on a laptop) starts again from the launch screen.

## Host it
Upload this folder to Netlify, Vercel or GitHub Pages. It is a static site: index.html plus three images.
